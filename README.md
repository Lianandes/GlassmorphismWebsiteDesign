# Glassmorphism Website Design

Projeto desenvolvido para praticar a criação de interfaces modernas utilizando o conceito de Glassmorphism com HTML e CSS.

## 🚀 Objetivo

O objetivo deste projeto foi aprimorar conhecimentos em design UI, estilização avançada e construção de interfaces modernas inspiradas no efeito glassmorphism.

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Design glassmorphism
- Interface moderna
- Efeitos de transparência
- Layout organizado
- Visual minimalista

## 📚 Conceitos praticados

- Glassmorphism
- Backdrop Filter
- CSS Effects
- Estilização moderna
- Design de interface
